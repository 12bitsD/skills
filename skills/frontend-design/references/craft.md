# 设计功底参考库

按 SKILL.md 各步点读。所有案例事实来自对 rsiarena.live 的解剖（2026-09-30），风格可换，功底通用。

## 概念与语义色（对应步骤 1–2）

- **一个概念统领命名**：BakeAI 用"烘焙+竞技场"双关——训练状态叫 Baking、服务器叫面包盒、GPU 空闲画成打瞌睡。判断标准：新元素起名时第一选择是从概念里长，不是从功能词典里查。
- **语义角色色 `--tone`**：每个实体（模型/agent/用户）一个颜色变量，它的徽章边框、角落标识、占用标记、轨迹卡底色全部 `var(--tone)`。换实体时一处改色全站跟，观者把"颜色"自然学成"谁"。
- **色板四层实例**：暖黑底（`#120d0a`）+ 象牙纸面（`#f3ead8`）+ 琥珀强调（`#df9d49`）+ pastel 角色色组。注意底色的色温——中性纯灰出"冷感"，带棕/蓝/绿的灰才有质感。
- **子集字体**：logo/专用 wordmark 用只含所需字符的子集 woff2（RSIBox Mono 六个字母 1.1KB）。
- **一个图形资产全站复用**：同一张 mascot 图，品牌处原样、对手处 `scaleX(-1)` 镜像、装置处裁剪——视觉统一最省力的做法。

## 质感手法（对应步骤 4）

| 手法 | 写法 | 效果 |
|---|---|---|
| 阴影画纸厚 | `box-shadow:0 .24rem 0 -.07rem C1, 0 .46rem 0 -.16rem C2`（递减偏移、零模糊、两三层） | 一叠纸的厚度，顶卡翻走牌堆仍在 |
| 贴片立体感 | `box-shadow:inset 0 .07rem .22rem rgba(ink,.4), 0 .05rem 0 rgba(white,.55)` | 徽章像嵌进去的珐琅片 |
| 遮罩渐隐 | `mask-image:linear-gradient(...)` 用在列表底部/弹幕两端 | 比阴影遮罩干净 |
| 数字不抖 | `font-variant-numeric:tabular-nums` 用于一切刷新中的数字 | 数据界面的基本信用 |
| 紧排标题 | `letter-spacing:-.01 ~ -.035em`（尺寸越大收越多） | 印刷感 |
| 单色图标 | `mask:url(icon.svg)+background:currentColor` | 图标随文字色，主题零成本 |
| SVG 任意缩放 | `vector-effect:non-scaling-stroke` + `transform-box:fill-box` | 描边一致、动画以自身为坐标 |
| 角色色衍生 | `color-mix(in srgb,var(--tone) 42%,#fffaf1)` | 不为每个实体手写一套色 |

## 版式缩放策略（对应步骤 3/7）

- **海报式**：`html{font-size:clamp(11px,min(.8333vw,1.4815vh),30px)}`，全站 rem，整页随视口等比缩放。用于数据屏/直播/展厅。配 `overflow:hidden` 单屏栅格（主区 ~60% 高）。
- **断点只减不挤**：逐级隐藏次要元素（连接状态→时钟→编号→标签），内容本身不压缩。移动端才切单列。
- 选择依据：观看距离远/不可交互 → 海报式；需要深阅读/操作 → 流式。

## 动效编排（对应步骤 6）

- **叙事微动效**：让状态"活着"的小循环（蒸汽、眨眼、开盖），频率 ≥3s 一轮、幅度 <10% 尺寸、共用一条缓动。
- **idle 淡出**：`body.idle .fade{opacity:0}`——无人操作时控件消失，纯观赏模式。广播/展板类产品值得抄。
- **降级**：尾块一刀切 `@media(prefers-reduced-motion:reduce){*{transition:none!important;animation:none!important}}`。
- **进度可视化**：轮播/轮转用 3px 进度条按周期线性生长（`scaleX` origin left），不显示秒数。

## 文案系统（对应步骤 5）

- 事件翻译规则：原始事件→人类标题，但**不认识的事件用原标题，绝不编造解释**（"never a fabricated explanation"）。
- 诚实后缀：训练完成="Training finished. Model quality still needs to be tested."；GPU 任务结束="Ran to the end; not yet known if the model improved."——不替实验下结论。
- 时间戳取舍：用结果时间戳而非提交时间戳，防止 50 分钟的任务在提交瞬间被报成完成。
- 空态原文实例：`Not reported yet` / `Waiting for GPU usage` / `4% of 1,000 GPU-hours`。

## 反模式清单（命中即返工）

1. 彩虹色板：强调色 >3 或颜色无语义分工。
2. 默认弥散投影全家桶：所有卡片同一个 `0 4px 16px rgba(0,0,0,.1)`。
3. emoji 当图标系统：无统一 grid/光学的 emoji 拼贴。
4. 动效承担唯一状态表达：只在动画里看得出的 running/live。
5. 风格漂移：纸感卡片和玻璃拟态同页出现；圆角体系有三个以上无关值。
6. 骨架屏糊弄：用假条目顶替空态/错误。
7. 色彩纯灰阶：底色无色温，页面出"医院感"。
8. 断点硬压缩：小屏上把内容挤变形而不是删减层级。

## 自查清单（交付前逐项打勾）

1. 风格声明一句话存在且全站不违背？
2. 任选三个元素，与概念的关系答得上？
3. 每个色值/动画时长都能答出语义？
4. 25% 缩放或灰度下 3 秒内能找到主角？
5. 每句话强调点 ≤1？每屏幕主角 =1？
6. 数字全部 tabular-nums？标题紧排？
7. 关闭全部动画后状态仍完整可读（decoration, never data）？
8. 空态/错误/不确定全部如实写出，无编造无骨架顶替？
9. 最小与最大目标屏各截一图，主信息成立？
10. 别人的话与界面的话，不看标签能分清？
11. 反馈与决策（日期+原因）写进了代码注释？
12. 反模式清单逐条过，零命中或有豁免理由？
